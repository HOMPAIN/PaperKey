# Точки на карточке

## Зачем

Карточка безопасна и без точек: печатные клетки выбирает криптографический генератор. Точки защищают от перехвата файла до печати — на компьютере, в очереди печати, в принтере. Тот, у кого есть файл, знает печатные клетки, но не знает, где ваши точки.

## Как ставить

Чёрным маркером в центр клетки, затем проверить на странице проверки: она покажет слабые и сомнительные точки и уровень защиты. На обе стороны ставьте примерно поровну.

## Сколько

Ниже — рекомендации по количеству. Бит на сторону: log₂ C(336, m) для m точек; бит на карточку — при одинаковом числе точек на обеих сторонах.

| Точек на каждой стороне | Что это даёт | Бит на сторону | Бит на карточку |
|---:|---|---:|---:|
| 0 | **нет** — перехват файла равен краже ключа | 0 | 0 |
| 5 | слабая | 35 | 70 |
| 10 | слабая | 62 | 124 |
| **11** | **средняя** — перебор нереален, если точки выбраны случайно | 67 | 134 |
| 15 | средняя | 85 | 170 |
| **18** | **хорошая** — есть запас на неслучайность выбора | 98 | 196 |
| 25 | хорошая | 125 | 250 |
| **26** | **сильная** — 256 бит на карточку, полная защита при перехвате файла | 128 | 257 |
| 40 | сильная | 173 | 346 |
| 60 | сильная | 223 | 447 |
| **77** | **максимальная** — 256 бит на каждой стороне, выдерживает перехват файла вместе с фото одной стороны | 257 | 513 |
| 168 | максимальная, предел | 332 | 663 |
| больше 168 | нельзя: каждая следующая точка уменьшает непредсказуемость | | |

Откуда берутся числа — в [оценке стойкости](security.md).
