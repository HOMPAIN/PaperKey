# PaperKey — бумажный ключ

Карточка размером с банковскую, на которой напечатана таблица клеток. В клетках — 256-битный секретный ключ. Наводите камеру телефона на обе стороны карточки и входите в приложение.

![Лист с карточкой PaperKey](docs/images/sample-sheet.png)

## Идея в трёх предложениях

Генератор печатает на каждой стороне таблицу 28 × 16 со случайно закрашенными клетками. Вы добавляете свои клетки маркером — так ключ защищён, даже если файл карточки перехватили при печати. Телефон читает обе стороны и вычисляет ключ; ни на карточке, ни в файле ключа в готовом виде нет.

Подробно, простым языком: [Карточка PaperKey — что это и зачем](docs/paperkey.md).

## Три уровня защиты, каждый — полный

| | От чего | Чем |
|---|---|---|
| 1 | Подбор ключа | Криптостойкая случайная печать: больше 2^358 вариантов на сторону |
| 2 | Фотография одной стороны | Ключ вычисляется из обеих сторон целиком |
| 3 | Перехват файла при печати | Клетки, которые вы закрасили сами. Уровень защиты — по их числу |

## Сборка

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```bash
dotnet build PaperKey.slnx
```

```bash
dotnet test PaperKey.slnx
```

```bash
dotnet run --project src/PaperKey.Web
```

Генератор откроется на http://localhost:5080.

```bash
dotnet run --project tools/PaperKey.Vectors
```

Последняя команда пересчитывает `docs/test-vectors.json`; значения мастер-ключа записываются только при совпадении двух реализаций Argon2id.
