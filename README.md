# PaperKey — бумажный ключ

PaperKey — это аналог пароля, записанного на бумажке. Только вместо слова, которое нужно запоминать и набирать, на карточке размером с банковскую напечатана таблица чёрных и белых клеток с 256-битным ключом. Чтобы войти, вы показываете карточку камере телефона.

![Готовые карточки PaperKey](docs/images/cards.jpg)

- [Описание карточки](docs/paperkey.md) — что это, как работает, как сделать и как пользоваться.
- [Приложение PaperKey](https://hompain.github.io/PaperKey/) — генератор, проверка и сканер карточки; работает целиком в браузере.
- [Спецификация формата](docs/SPEC.md) — геометрия, чтение, вычисление ключа и тестовые векторы; по ней можно написать свой сканер.

В репозитории — исходный код приложения и [описание кода](docs/code.md).
